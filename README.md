# R-APP (تطبيق مزارع الرشيدي للدواجن)

تطبيق متجر إلكتروني متكامل لمزارع الرشيدي للدواجن، مبني باستخدام **React Native (Expo)** و **Firebase**.

## ✨ المميزات الرئيسية
- 🛒 تجربة تسوق إلكتروني متكاملة (سلة مشتريات ذكية، طلبات مخصصة، إضافات وتقطيع حسب الطلب).
- 📱 شاشة تسجيل دخول سريعة ومحسنة مع دعم المصادقة عبر الهاتف وكلمة المرور.
- 📢 شريط «يوميات الرشيدي» لعرض القصص والعروض الحصرية.
- 🚚 إدارة وتتبع فروع الإسكندرية ومناطق التوصيل.
- 📊 لوحة تحكم إدارية متكاملة (Dashboard) لمتابعة الطلبات، الإيرادات، والمبيعات بالرسوم البيانية.
- 🔔 تنبيهات صوتية وإشعارات فورية عند ورود طلبات جديدة.
- 📱 تطبيق هاتف محمول مدمج وخفيف الوزن (APK) جاهز للتثبيت المباشر.

## 🛠️ التقنيات المستخدمة
- **Framework:** React Native / Expo (SDK 52)
- **Backend & Database:** Google Firebase (Firestore, Firebase Storage, Firebase Auth, Cloud Functions)
- **Icons & UI:** Ionicons, Lucide, Custom Typography & Design System
- **Testing:** Comprehensive Automated Test Suite (136/136 Passing)
